## 一句话原则（写在这里防止后面走偏）

- **可解释**：说不清为什么，就不展示
- **可操作**：每个结论都要能落成一个动作
- **不编造**：估的要标「估」，没做的要说没做
- **纯本地**：不登录、不上传、数据在浏览器里
