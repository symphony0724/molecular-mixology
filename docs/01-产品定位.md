# 01 · 产品定位

## 一句话

**一个"能看见化学"的调酒设计台**：选食材 → 看见它由哪些风味分子构成 → 看见它和别的食材会
发生什么（提香、压味、沉淀、变色、乳化）→ 据此推出可执行的特调配方。

## 和现有产品的差别

| 现有做法 | 本产品 |
|---|---|
| 配方网站：给现成配方 | 给**设计方法**，配方是自己推出来的 |
| 风味轮 App：给"果香/花香"标签 | 落到**具体分子**（乙酸异戊酯、柠檬烯、丁香酚…）与阈值 |
| 调酒师经验：口口相传"柑橘配罗勒" | 把经验**归因**到化学机制并可检索 |
| 分子料理书：讲技法 | 技法与**食材数据联动**，选完食材自动推荐可用技法 |

## 三类目标用户

**A. 家庭调酒爱好者（主力）**
想做一杯不像"朗姆+可乐"的东西。要的是：给我灵感、告诉我为什么、别让我浪费一瓶酒。
→ 需要：入门友好、有推荐、有"避坑提示"。

**B. 专业调酒师 / 酒吧研发**
要做季节菜单、要稳定复现、要给客人讲故事。
→ 需要：精确比例、ABV/糖度/酸度计算、批量放大、配方卡导出、可解释的风味描述。

**C. 食品科学 / 烹饪学生**
把它当教学工具：分子性质、阈值、pH 依赖、美拉德、乳化。
→ 需要：数据来源、CAS 号、公式、可引用。

## 核心场景（用户旅程草案）

### 场景 1：我有材料，想知道能做什么
① 从"我的酒柜"勾选手头的 5 样东西 → ② 系统算出所有**两两交互**（绿=协同 / 黄=需注意 /
红=冲突）→ ③ 给出 3 条可行路线（例：走向清爽酸香 / 走向奶洗圆润 / 走向烟熏辛香）→
④ 点开任一路线得到配比与步骤。

### 场景 2：我想突出某个味道
① 输入目标："想要一杯有烤面包和香蕉、但不要太甜的" → ② 系统反查：香蕉=乙酸异戊酯，
烤面包=2-乙酰基吡嗪/糠醛，降甜=提高酸度或用单宁/盐 → ③ 给出分子来源食材候选 → ④ 组合成配方。

### 场景 3：我要排查一杯失败的作品
① 输入现有配方 → ② 诊断：为什么浑浊了（酪蛋白遇酸）/ 为什么香气没了（酒精度过高抑制挥发）/
为什么发苦（过度压榨柑橘皮白瓤的柠檬苦素 + 氧化）→ ③ 给修正方案。

## 价值主张（写在首页上的三句话）

- 每一种食材，都能拆开看它的**风味分子清单**。
- 每一次搭配，都能看到**为什么搭 / 为什么不搭**。
- 每一杯特调，都能算清**比例、酒精度、甜酸度、稀释度**。
