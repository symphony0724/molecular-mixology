# 19 · 反应表（v1.12）

> 样张：`samples/16-反应表.html` · 数据：`data/reactions.json`（12 条）· 生成：`node scripts/build-reactions.mjs`

这是四张数据表的最后一张（表 A 食材 / 表 B 基底 / 表 C 结构分子 / **表 D 反应**），也是唯一一张「按时间发生」的表。

## 1 · 为什么叫「反应表」而不是「技法步骤」

技法是**人做的事**（慢煮 65℃ 90 分钟）；反应是**东西自己发生的事**（酯水解、萜烯氧化）。

同一件事在两个尺度上：

| 你做的 | 它顺带发生的 |
|---|---|
| 65℃ 慢煮 90 min | 细胞壁破裂、果胶水解、香气溶出（想要的） |
| 同上 | 超过 120 min 开始萜烯氧化（不想要的） |

所以表 D 不是步骤，是**判据**：给定温度、pH、时间、氧、光，判断哪些反应在跑、跑得多快、对成品合不合意。

## 2 · 十二条，按判定分三组

| 组 | 条数 | 成员 |
|---|---|---|
| **想要的**（desired，墨绿） | 5 | R1 酯化 / R7 花青素 pH / R8 酪蛋白等电点 / R9 乌佐效应 / R10 酶解澄清 |
| **看场合**（contextual，铜） | 3 | R3 美拉德 / R4 焦糖化 / R12 乙醇-水缔合 |
| **要避免**（avoid，朱砂） | 4 | R2 酯水解 / R5 萜烯氧化 / R6 多酚氧化 / R11 铁-多酚 |

按判定分组而不是按化学类别分组，是因为用户的真实问题是「这个反应对我的酒是好是坏」。按酯化/氧化/水解分组，回答的是化学课本的问题。

## 3 · 数据结构

```jsonc
{
  "id": "r8-casein-isoelectric",
  "no": "R8",
  "zh": "酪蛋白等电点沉淀", "en": "Casein isoelectric precipitation",
  "mode": "chemical | physical | equilibrium",
  "condText": "pH ≤ 4.6 · 加酸",          // 给人看的一行条件
  "conditions": { "ph":[3.5,4.6], "tempC":[4,25], "timeH":[0,2] },
  "reactants": ["compound:casein", "class:acid"],
  "products": [{ "match":"class:casein-curd", "sensoryDelta":"絮凝 · 澄清 · 香气变干净" }],
  "rate": "instant | minutes | hours | days | weeks",
  "reversible": false,
  "verdict": "desired | contextual | avoid",
  "mechanism": "…",                        // 必填，UI 直接显示
  "teaching": "…",                         // 调酒里的人话
  "avoid": "…",                            // 仅 avoid 组
  "evidence": "literature | mechanism | consensus"
}
```

**`conditions` 是区间不是开关**，因为阈值有宽度：pH 从 4.7 降到 4.4，奶洗才真的开始分层；温度每升 10℃，速率大约快 2 倍。

**`match` 支持三种写法**：`compound:<id>` 具体分子、`class:<类>` 任意具该类结构的分子、`enzyme:<id>` / `ion:<id>` 工具或离子。

## 4 · 四个刻意的写法

**① 反例也有条目。** 只写「该做什么」的表会让人以为没写的就不会发生。R2/R5/R6/R11 是**一直在后台跑的**，每条都给了「怎么避免」。

**② 调酒里那句话用楷体单独一行。** 机理是教科书语言，「摇壶里不会发生酯化」才是能用的知识。

**③ R7 标成 equilibrium 不是 chemical。** 花青素变色是平衡移动，不是生成新物质——这个区别决定了它**可逆**，也决定了「颜色变了再调回来」是可行的。

**④ R12 是唯一影响计算的条目。** 乙醇-水缔合导致 50+50 ≠ 100（50% v/v 时收缩约 3.6%），配方台的体积必须按质量算再折体积。它躺在反应表里，是因为它确实是反应——只不过这个反应的「感官结果」是**你的 ABV 算错了**。

## 5 · 与资料库的关系

资料库第五类（反应）现在有 JSON 了，列表可以真正跑起来：

```
反应列表 ← data/reactions.json
  ↓ 点 R8
R8 详情：条件条（pH/温度/时间三档刻度）+ 反应物 → 产物 + 机理 + 调酒里 + 相关技法 T8 + 出现在哪些配方
```
