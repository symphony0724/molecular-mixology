## 1 · 三种模式，这一版只画了反应台

| 模式 | 做什么 | 状态 |
|---|---|---|
| 工坊 WORKSHOP | 只摆分子：按香族聚簇 / 按 logP×阈值散点 / 共享子结构高亮 | 未画 |
| **反应台 REACTION** | 拖近 → 预演反应 → 拨条件 → 看进度与阈值 | ✅ 本样张 |
| 映射台 MAPPING | 反查现实：这个组合在真实调酒里叫什么、用哪条技法、多少量 | 按钮已留，未画 |

三者共用同一套 `BenchState`（节点 + 条件 + 连线），切换模式不丢内容——所以先做最复杂的一个，其余两个是它的子集。

## 2 · 台面上摆的是分子，不是食材

这是它和配方台最根本的区别：

- 配方台：`金酒 50 + 黄瓜汁 30` → 一杯酒，单位是 ml。
- 分子台：`d-柠檬烯 + O₂` → 香芹酮，单位是 mg/L 与转化率。

食材 → 分子的映射在资料库里（「哪些食材含它」），不在这张台面上。**台面只认分子**，否则语义会立刻混乱：「番茄」到底是番茄红素、谷氨酸还是己烯醛？

## 4 · 三个诚实处理

**① 不适用也要给原因，不给空白。**
R2 显示「不适用 · 还差：台面上没有任何酯」，R6 显示「还差：缺多酚，也缺酶（酶已被 65℃ 灭活）」。空着等于让用户以为没写就是不会发生。

**② 阈值倍数永远带误差。**
`0.24×` 下面写着「含量为分级估算，误差 ±3–10 倍」。这句话很丑，但它防止用户把界面当仪器。

**③ 判定 ≠ 安全。**
「要避免」是成品合不合意的判断，不是危险度。苯甲醛天然存在于杏仁，不代表可以乱加；反过来 R5 产物香芹酮是合法香料，但在柑橘汁里它意味着「放坏了」。

## 5 · 与其它页的分工

```
资料库      ← 查「这是什么东西」（阈值、CAS、出现在哪）
分子台   ← 造「这个东西怎么来、放着会变成什么」（反应 + 条件）
技法台      ← 做「现实里怎么让条件成立」（慢煮、旋蒸、离心）
配方台      ← 调「比例与读数」（一杯酒的 ABV / 糖 / 酸）
推荐台      ← 起点「我有什么」→ 五杯
```

分子台的产物可以通过映射台落回技法台（「想快速得到香芹酮？不可能的，它是氧化产物，你只能加速或避免」）。
