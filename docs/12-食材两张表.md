---

## 1. 为什么拆成两张

原方案是一张 60 条的「食材」表，把基酒、蔬果、糖浆混在一起。问题：

1. **"我有什么"这个问题被污染了**。用户问的是"我冰箱里这几样能做什么"，结果一半选项是他买不起的基酒。
2. **数据性质不同**。蔬果要的是分子与风味；基底要的是 ABV / 糖 / 酸 / 气泡 / 密度——后者是**可加总的数值**，
   前者是**不可加总的气味描述**。混表会让字段一半永远空着。
3. 用户家里通常只有 3–6 支酒，选基酒是**一次性动作**；蔬果香料才是每次都变的变量。

结论见 **ADR-018**。

**比原定的 60 多 6 条**：香草与干果分得比预想细，且补了竹叶/斑斓叶/香茅三条"本土与东南亚"的常用项。

### 每条包含 5 行

1. **关键分子**：3 个，从 143 条分子表里引用，前面 `●●●` 表示它是不是这一项的主角（强/中/弱），不表示绝对含量
2. **活性成分**：不挥发但决定成败的（果胶、花青素、单宁、蛋白酶、辣椒素、蒜素…）
3. **数值**：pH / 糖 g/100g / 酸 g/100g + 适用技法 id（T1–T20）
4. **搭配**：可配的其他食材（蔬果黑字、基底绿字）
5. **一句话**：为什么它值得用 + **风险红字**

### 数据字段

```ts
interface Ingredient {
  id: string; zh: string; en: string;
  fam: "fruit"|"vegetable"|"herb"|"spice"|"flower"|"dried";
  season: string;                    // 应季时间，用于"现在什么最好"
  ph: number; sugar: number; acid: number;
  aroma: [compoundId, "dominant"|"high"|"mid"|"low"][];
  actives: string[];
  texture: string; prep: string;
  tech: TechniqueId[];               // 适用技法
  pairs: (IngredientId | BaseId)[];
  risk: string; note: string;
}
```

## 3. 表 B · 基底液体（32 条）

| 类别 | 数量 | 例子 |
|---|---|---|
| 烈酒 spirit | 9 | 伏特加 金酒 朗姆 龙舌兰 梅斯卡尔 威士忌 波本 白兰地 白酒 |
| 发酵酒 wine | 8 | 黄酒 米酒 梅子酒 清酒 味美思 金巴利 干型雪莉 干白 / 干红（11 条含啤酒苹果酒另计） |
| 气泡 fizzy | 5 | 苏打水 汤力水 姜汁汽水 可乐 |
| 无酒精 nonAlcohol | 1 | 椰子水 |
| 乳与质地 dairy | 2 | 牛奶 淡奶油 |
| 甜味 sweet | 5 | 蜂蜜糖浆 单糖浆 杏仁糖浆 可可利口酒 |

**角色（role）是这张表最重要的字段**：

- `base` 基酒：给骨架，40% 左右，决定酒体
- `modifier` 调味：给方向（金巴利、味美思、黄酒、可可利口酒）
- `dilution` 稀释：给长度与气泡（苏打、汤力、啤酒、椰子水）
- `sweetener` 甜味：给平衡（糖浆、蜂蜜、杏仁糖浆）
- `texture` 质地：给口感（牛奶、淡奶油）

> 一张配方 = 1 个 base + 0–2 个 modifier + 0–1 个 sweetener + 0–1 个 dilution。
> 这个结构是推荐台"骨架匹配"的直接依据。

## 4. 两张表怎么在界面上汇合

选材料分两步，但视觉上在同一屏：

```
① 我有什么蔬果香料   ←  表 A，多选，决定「风味」
② 我有什么酒和气泡   ←  表 B，多选，决定「酒体」
```

- 表 A 的选择进入 `cover`（香调覆盖度）与 `facet` 匹配
- 表 B 的选择进入 `structure`（酒体/甜酸/气泡）与 ABV 计算
- **只勾表 A 也能出方案**：输出会是无酒精特调（Mocktail），这正是 X2 决策要求的
- **只勾表 B 不能出方案**：会提示"再加一样有味道的东西"

## 5. 已知缺口

- 坚果类（核桃 / 榛子 / 芝麻）未收录——它们分子谱和"熟果"重叠，需要单独判定
- 乳制品（酸奶 / 奶酪 / 黄油）未收录——奶洗用得到，但归"质地"还是"食材"没定
- 部分特征分子不在 143 条表里：**覆盆子酮（树莓酮）**、**辣椒素**、**胡椒碱**、**大蒜素**、**姜辣素**、**山楂酸**、**茶多酚**
  —— 它们多数**不挥发**，按 ADR 计划应进"结构分子表"（另开）
- 应季时间是北半球温带口径，南方/进口货会不一致
