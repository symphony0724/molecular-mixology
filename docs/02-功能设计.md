## M1 · 食材库与检索 `[P0]`

- 分类浏览：基酒（金酒/朗姆/威士忌/龙舌兰/伏特加/白兰地/中国白酒）· 利口酒 · 葡萄酒/加强酒 ·
  果汁与果泥 · 糖浆 · 苦精 · 乳制品 · 蛋 · 香草香料 · 茶咖啡 · 气泡 · 其他（醋、盐、酱油…）。
- 每个食材一张**卡片**：产地/工艺、主要风味族、关键分子 Top 5、ABV、糖度、pH/总酸、典型用量。
- 检索：中文名 / 英文名 / 别名（"香菜=芫荽=coriander"）/ 按分子反查（"哪些食材含丁香酚"）。
- `[P0]` 筛选器：按风味族、按酒精度、按"我冰箱里有"。
- `[P1]` **我的酒柜**：勾选拥有的食材，全局只看能用上的。

## M2 · 成分名片（风味分子档案）`[P0]`

单个分子的详情页：

| 字段 | 例（乙酸异戊酯） |
|---|---|
| 中文名 / 英文名 | 乙酸异戊酯 / Isoamyl acetate |
| CAS | 123-92-2 |
| 风味描述 | 香蕉、梨、糖果、香蕉水 |
| 嗅觉阈值 | 水中 ≈ 0.03–0.2 mg/L（数值随文献差异大，标注区间与来源） |
| 沸点 | 142 °C |
| logP | ≈ 2.26（亲脂 → 更易留在酒体/油脂中） |
| 风味族 | 果香-酯类 |
| 典型来源 | 香蕉、梨、酵母发酵、朗姆酒 |
| 稳定性/降解 | 碱性条件下水解；久置氧化 |

- `[P0]` 用**阈值刻度条**直观展示"这个分子在多少浓度能被闻到"。
- `[P1]` 分子式 + 2D 结构式渲染。
- `[P1]` "同类分子"推荐（同族 → 可互相替代的思路）。
- `[P2]` 阈值受基质影响（水/10% 乙醇/40% 乙醇/含糖）的对照数据。

## M3 · 交互引擎（核心）`[P0]`

输入两个（或多个）食材，输出**交互报告**：

1. **感官交互**：协同增效 / 掩蔽 / 抑制 / 加成 / 无感（依据共享分子族 + 阈值 + 已知感官研究）。
2. **化学交互**：会发生什么反应（酯化、美拉德、氧化、酸碱沉淀、变色、水解、絮凝）。
3. **物理交互**：乳化、起泡、凝胶、分层（密度差）、冰点、浑浊（乌佐效应）。
4. **结论**：`推荐 / 可用需注意 / 不建议`，配一句人话解释 + 一条操作建议。

每条结论必须挂**证据等级**：`实验/文献支持` > `机理推断` > `经验共识` > `待验证`。

`[P0]` 两两查询。 `[P0]` 结果可收藏成"我的搭配笔记"。
`[P1]` 三材以上联合分析（简单叠加 + 冲突检测）。
`[P1]` 一次看全部：选中 3–8 个食材 → **交互矩阵热力图**。

## M4 · 风味可视化 `[P0]`

- **风味雷达**：甜 / 酸 / 苦 / 鲜(umami) / 辛 / 香 / 醇厚(body) / 收敛 — 0–5 分。
- **风味族条形**：果香、花香、柑橘、草本、辛香、木质、烘烤、乳香、烟熏、土质、硫味、发酵。
- `[P1]` **分子网络图**：节点=食材，连线=共享分子/交互，线粗细=强度（可点击连线看原因）。
- `[P1]` 分子"指纹"对比：两食材共享哪些分子（交集高 = 天然和谐，如 柑橘↔ 芫荽籽 都有芳樟醇）。

## M5 · 特调工作台 `[P0]`

一个配方 = 若干"配料行"（食材 + 用量 + 单位）。

实时计算面板：
- **ABV**（按体积分数与密度修正，需酒精度-密度换算表）
- **糖度**（g/100 mL，与 Brix 对应）
- **总酸**（以柠檬酸当量 g/L）与**估算 pH**
- **苦度**（自定义 0–10 的"苦感指数"，非 IBU）
- **稀释度**：摇和 ≈ 20–25% 水量、搅拌 ≈ 15–20%、直调 0%（按冰量/时间可调）
- **最终体积 / 杯型建议 / 冰型建议**
- **平衡诊断**：酸甜比（Sour 经典区间 sour:sweet ≈ 1:1 ~ 1:1.5）、酒精强度是否压住香气、稀释是否足够

`[P0]` 单位：`ml / oz / dash / barspoon / tsp / g`，一键切换显示。
`[P1]` 配方缩放（1 杯 → 1 L 预调瓶），含"加水/加酸补正"。
`[P1]` 一键生成**配方卡**（图片/PDF，可打印贴吧台）。

## M6 · 技法与化学效应库 `[P0]`

按"你要的效果"索引，而不是按技法名：

| 想要的效果 | 技法 | 化学原理 | 关键控制点 |
|---|---|---|---|
| 澄清但保留奶香 | 奶洗 Milk Washing | 酸性使酪蛋白达等电点(pH≈4.6)絮凝，吸附脂溶性香气后过滤 | 酸量、静置时间、过滤层 |
| 清澈的果汁 | 酶澄清 / 明胶-硅胶 | 果胶酶水解果胶；明胶-单宁絮凝 | 温度、剂量、时间 |
| 稳定的泡沫 | 卵清蛋白 / 大豆卵磷脂 / 起泡剂 | 蛋白质界面膜；卵磷脂降低表面张力 | 打发强度、脂肪含量（脂肪会破泡） |
| 球化爆珠 | 海藻酸钠 + 乳酸钙 | 钙离子交联海藻酸形成凝胶外壳 | 钙浴浓度、时间 |
| 冷烟熏 | 烟熏枪 / 愈创木酚、4-甲基愈创木酚 | 酚类附着与溶解 | 时间、密封、湿度 |
| 清澈透明的"酒感" | 酸调 Acid-adjusted | 用酸粉替代果汁，减水增香 | 酸的种类与当量 |
| 风味浸渍 | 快速浸渍 / 真空 / 脂肪洗 Fat-wash | 相似相溶（logP 匹配） | 时间、温度、过滤 |
| 自发浑浊 | 乌佐效应 Ouzo Effect | 茴香脑等疏水物遇水过饱和 → 自发纳米乳化 | 加水速度、酒精度 |

- `[P0]` 每个技法页：原理图 + 步骤 + 失败原因排查表。
- `[P1]` **反向推荐**：在工作台选完食材后，自动提示"这批材料适合做奶洗/适合做气泡/不适合乳化"。

## M10 · 无酒精模式 `[P0]`

- 全局开关：所有计算按 ABV=0 处理，"酒精强度"维度替换为"酒体/辛辣感"。
- 无酒精基底库：茶（含单宁/咖啡因）、咖啡、气泡水、康普茶、果汁、无醇烈酒替代、醋饮。
- 额外提示：无酒精体系缺少乙醇作为溶剂 → **疏水香气承载能力差**，需要
  乳化（卵磷脂/阿拉伯胶）、糖浆增稠或少量油脂来"抓住"香气。这是无酒精特调最容易翻车的地方，必须做成一条规则。
- `[P1]` "含酒精版 ↔ 无酒精版"一键互转（把 45 ml 金酒换成 X ml 茶 + 少量苦精）。

## 本土食材包（首版必备）`[P0]`

**白酒**（酱香=大量吡嗪/呋喃与 4-乙基愈创木酚；浓香=己酸乙酯为主；清香=乙酸乙酯为主）、
**黄酒**（焦糖色/麦芽酚/醛类）、**梅子酒**、**陈皮**、**桂花**、**洛神花**（花青素+高酸）、
**山楂**、**话梅**（盐+酸+发酵香）、**茉莉花茶**、**乌龙**、**枸杞**。

> 这一包是产品的辨识度所在：国外同类产品基本没有这套数据，而它们恰恰是"特调"最好用的风味素材。

## 明确不做（v1 范围外）

- 不做社交/社区/评论。
- 不做电商或买酒导流。
- 不做真实化学计算（量子/分子动力学），操作台只用规则 + 查表 + 示意动画。
- 不做 AI 自动生成配方作为核心（仅 P2 可选插件）。
