# 04 技法推荐 —— 入口页交互说明

> 对应 `samples/04-技法推荐.html`。这一页回答的问题是：**我手上有这些东西，能对它做什么？**

---

## 一、为什么不是"技法列表"

用户原话（m00417）：

> 我需要的是选择材料之后再推荐并选择技法，而不是把所有技法列出来

从 20 个陌生名词里挑一个，用户没有判断依据——他不知道"低温慢煮"和"油洗"对草莓意味着什么差别。
**材料是用户唯一确定知道的东西**，所以入口必须是材料。技法清单是答案，不是问题。

顺序倒过来之后，用户的思考负担从「20 选 1」降到「3 选 1」，而且每一次推荐都在教他一点化学。

---

## 二、三段式流程

```
① 选材料  →  ② 选目标  →  ③ 推荐 3 条  →  [用这个技法] → 参数工作台
```

### ① 选材料

- 芯片式：`草莓 200 g ×`、`伏特加 200 ml ×`……可加可删
- 支持直接打字：*"还有半颗青柠和一点迷迭香"* → NLP 解析成材料 + 用量
- 从酒柜一键导入（我的酒柜 12）
- 每个材料后台会被打成 role：`溶剂 / 被萃取物 / 结构剂 / 酸源 / 糖源 / 乳蛋白 / 酶底物 / 色素源`

### ② 选目标

| 选项 | 影响的排序维度 |
|---|---|
| 更香 | 香气保留率、挥发性物质得率 |
| 更清澈 | 澄清度、浊度下降、过滤可行性 |
| 更有口感 | 黏度、凝胶强度、气泡持久度 |
| 更好看 | 色泽饱和度、透明度、造型可行性 |
| 更省事 | 步骤数、设备依赖、等待时间 |

**同一批材料没有唯一正确答案**——换目标排序就变，这句话要写在界面上。

### ③ 推荐

只给 **3 张卡**。宁可少，不可错——推荐错了比不推荐更伤信任。

每张卡必须回答四件事：

| 字段 | 回答的问题 | 为什么必须有 |
|---|---|---|
| 适配度 % | 这条技法有多适合这批材料 | 可比较，避免"都对" |
| 为什么是它 | 化学层面的理由 | 无解释不展示 |
| 材料角色 | 每样材料在这条技法里扮演什么 | 用户才知道"原来伏特加是溶剂" |
| 参数摘要 / 产物 / 风险 | 大概会得到什么、会在哪失败 | 三个数就能做决定 |

点「用这个技法 →」进入 v0.6 那张参数工作台（`samples/03-技法工作台.html`），参数已经预填成推荐值。

## 三、不可用技法：必须显示，并说明原因

右栏固定一块「为什么另外 4 条用不了」。这是本产品与一般推荐算法的分野：

> **奶洗 T8** —— 缺乳蛋白：奶洗靠酪蛋白在 pH 4.6 絮凝，这批材料里没有乳制品。
> **球化 T13** —— pH 太低：柠檬汁把体系拉到 3.1，海藻酸钠在 pH < 3.5 不成胶，要走反向球化。
> **旋转蒸发 T5** —— 缺设备：需要 100–200 mbar 真空泵，设置里没勾"我有这台设备"。
> **油洗 T2** —— 方向不符：油洗带走脂溶性香气，草莓的水溶性果香会损失大半。

用户看完"为什么不行"，比看三条"为什么行"学到的更多。
**不适用 ≠ 不显示。**

## 四、筛选算法：`TechniqueSolver.filter()`

```
材料清单
   │
   ├─ 1. 角色匹配      材料的 role 集合 ∩ 技法所需 role
   ├─ 2. 条件冲突检查  混合后 pH / 乙醇 / 糖度 / 温度 落入技法安全区？
   ├─ 3. 设备可用性    用户已勾选的设备 ⊇ 技法必需设备？
   └─ 4. 目标加权      按 ①香气 ②澄清 ③结构 ④颜值 ⑤步骤数 打分排序
   │
   ▼
推荐 3 张 + 不可用清单（含原因）
```

第 2 步是核心：它不是查表匹配"草莓适合慢煮"，而是**真的算一遍**这批材料的混合 pH 和乙醇浓度，
再看落不落在技法的安全区间里。所以"柠檬汁 15 ml 把 pH 拉到 3.1 导致球化失败"这种结论是算出来的，不是编的。

## 五、降级处理

20 条技法目录从"默认入口"降级为"词典"，只在两处出现：

1. 资料库 → 技法栏（按族浏览）
2. 技法台右下角 `全部 20 条技法 →`

**它是词典，不是菜单。**

## 六、右栏「这批材料怎么读」

固定显示，四行，写清系统把每样材料读成了什么：

| 材料 | 判定 | 关键数值 |
|---|---|---|
| 草莓 | 软果 | 果胶高、含水 90%、pH 3.5 —— 适合萃取，怕高温 |
| 伏特加 | 中性烈酒 | 40% ABV、几乎无自身风味 —— 这里是溶剂，不是基酒 |
| 柠檬汁 | 酸源 | pH 2.2、15 ml 约 0.9 g 柠檬酸 —— 会拉低整杯 pH |
| 蜂蜜 | 糖源 | 果糖为主、黏度高 —— 抑制凝胶，出锅后再加 |

作用有两个：一是让"为什么只有这三条"变得透明；二是让用户慢慢学会自己判断——
下次不需要系统，他也知道"有柠檬汁就别想直接球化"。
