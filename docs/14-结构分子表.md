# 14 · 结构分子表：不靠闻的那一半

> 版本 v1.5 · 2026-11-11
> 数据：`data/structures.json`（47 条）· 页面：`samples/10-结构分子表.html`（脚本生成）

## 1. 为什么需要第三张表

前两张表处理的都是「香」：

- `data/compounds.json` —— **143 条挥发分子**，有阈值、有时间层，管「闻得到什么」
- `data/ingredients.json` / `bases.json` —— **80 条食材 + 32 条基底**，管「手上有什么」

但它们合起来解释不了这几件事：

| 现象 | 挥发分子表能解释吗 | 结构分子表能解释吗 |
|---|---|---|
| 奶洗后变清 | ✗ | ✓ 酪蛋白等电点 pH 4.6 |
| 洛神花加小苏打变蓝 | ✗ | ✓ 花青素 pH 变色 |
| 酒变黑 | ✗ | ✓ Fe³⁺ + 多酚络合 |
| 球化失败 | ✗ | ✓ 海藻酸钠在 pH < 3.5 不成膜 |
| 花椒的「麻」 | ✗（麻不是味觉也不是嗅觉） | ✓ 羟基山椒素 50 Hz 振动错觉 |
| 茶放凉变浑 | ✗ | ✓ 儿茶素 + 咖啡因「冷后浑」 |

**结论：香气管一半，结构管另一半。** 缺了这张表，03 技法工作台里的奶洗、球化、澄清、变色全是空壳。

## 3. 字段

```jsonc
{
  "id": "st-casein",
  "zh": "酪蛋白", "en": "Casein",
  "cls": "protein",          // 八个类之一
  "cas": "9000-71-9", "formula": "—",
  "water": 1,                // 0 不溶 / 1 微溶 / 2 可溶 / 3 易溶
  "effect": "等电点 pH 4.6 凝聚沉淀，这就是奶洗的原理",
  "cond": "pH 4.4–4.8 迅速絮凝；乙醇 > 30% 也会沉",
  "from": ["ing-milk", "ing-yogurt"],   // 表 A/B 的食材 id
  "tech": ["T8", "T12"],                // 03 技法工作台的技法号
  "conf": "lit"                          // lit 文献 / est 估算
}
```

三个字段是这张表的价值所在：

- **`cond` 条件** —— 不是「它是什么」，而是「它什么时候发作」。这是能不能用某个技法的唯一判据。
- **`tech` 技法号** —— 把分子直接挂到 03 的技法上，形成「点技法 → 看到它在动哪些分子」的反向索引。
- **`water` 水溶性** —— 决定它进果汁还是进油，也解释了为什么油洗能带走辣椒素却带不走糖。

## 4. 自我限制（写在页脚，也必须写在这里）

1. **分子式多为示意**。多酚、蛋白、多糖是混合物，给不出单一体；写了「—」就是真的没有单体。
2. **CAS 只对单一化合物有效**，混合物条目的 CAS 是「—」。
3. **水溶性是四级估**（不溶/微溶/可溶/易溶），不是溶解度实测值。
4. **「来自」只列了表 A/B 里出现过的食材**，不代表其他食材没有。
5. 47 条远未穷尽：还缺 K⁺、硫酸盐、碳酸氢盐、酶（果胶酶/蛋白酶）、明胶替代品（素胶）、以及全部「异味」类（TCA 已在挥发表）。

## 7. v1.6 修订（用户：「按你说的全加」）

三处都加了：**酶**、**限量与风险**、**三元溶解度**。条目从 47 → **53**，类从 8 → 9。

### 7.1 新增第九类：酶（工具，不是成分）

| 酶 | 作用 | 工作条件 | 用在 |
|---|---|---|---|
| 果胶酶 Pectinase | 30 分钟把浑浊果汁变清 | 40–50℃，pH 3.5–5.0，30–120 min；>70℃ 失活 | T11 T12 |
| 蛋白酶 Protease | 水解蛋白，减浑浊与苦味，也软化明胶 | 50℃，pH 5–7；>70℃ 失活 | T11 |
| 凝乳酶 Rennet | 专切 κ-酪蛋白，使牛奶凝固 | 35–40℃，pH 6.2–6.5；酸或 >50℃ 失效 | T8 T14 |
| 淀粉酶 α-Amylase | 把淀粉切成糖，降浑浊、增甜 | 60–70℃，pH 5–7 | T11 |
| 纤维素酶 Cellulase | 分解纤维素，提高出汁率 | 45–55℃，pH 4–5，1–3 h | T11 T12 |
| 柚皮苷酶 Naringinase | 把柚皮苷（苦）水解成不苦的普鲁宁 | 50℃，pH 3.5–5，1–2 h | T11 |

**为什么把酶单独成类**：其他八类回答「杯子里有什么」，酶回答「杯子里正在发生什么」。它没有风味、没有阈值、没有 CAS 意义上的单一分子——**它是条件本身**。所以字段里 `effect` 写作用、`cond` 写工况，`sol` 一律「易溶·不溶·不溶」（都是蛋白）。

一个顺手捡到的知识点写进了条目：**明胶甜点放鲜菠萝不凝**，因为菠萝蛋白酶把明胶水解了。

### 7.2 新增字段 `tox`（限量与风险）

```jsonc
"tox": { "lv": 0 | 1 | 2, "note": "…" }
```

- `0 安全` —— 常规用量安全，界面上显示为灰色「—」，不占注意力
- `1 注意` —— 有剂量或人群问题（咖啡因、草酸、皂苷、辣椒素、胡椒碱、大蒜素、硫代葡萄糖苷、缩合/水解单宁）
- `2 限量` —— 出了名会坏事的（铁离子 >5 mg/L 致酒变黑、铜离子催化褐变、草酸与钙）

**这不是毒理数据库**，是「什么时候该停手」的提示。页脚也这么写。

值得一提的两条：
- **胡椒碱**：显著提高多种物质（含药物）的生物利用度——所以「服药期间别大量吃黑胡椒」是真实建议。
- **铁离子**：果酒中 > 5 mg/L 就浑浊变黑，这是「别用铁器装酸性果汁」的分子级理由。

### 7.3 `water` → `sol`（水 / 醇 / 油 三元）

```jsonc
"sol": { "w": 3, "e": 1, "o": 0 }   // 0 不溶 / 1 微溶 / 2 可溶 / 3 易溶
```

界面上显示成 `易·可·不`（水·醇·油）。这一列解释了很多「为什么只能这么做」：

- 辣椒素 `不·易·易` → 水洗不掉，只能用脂肪或乙醇
- 姜黄素 `微·易·易` → 水煮提不出颜色，必须油或酒
- 柠檬酸 `易·可·不` → 不会跑到油里，所以油洗去不掉酸
- 羟基山椒素 `不·易·易` → 花椒的麻只能靠油或酒提
- 海藻酸钠 `易·不·不` → 只能在水相里球化

### 7.4 修订后的自我限制

> 溶解度是水/醇/油三档粗估，不是实测值；限量只是定性提示，不是毒理阈值，不用于安全判定；酶是「工具」不是「成分」，条目写的是工作条件而不是含量。
